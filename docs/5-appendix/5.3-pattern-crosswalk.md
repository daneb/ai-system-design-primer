# 5.3 Pattern crosswalk

Every provider and author names the same few patterns differently. This page lines the names up, so
you can read Anthropic's guidance, a cloud provider's architecture centre or a patterns book and know
which primer section it belongs to.

## How to read it

- **Rows are concepts; cells are what each source calls them.** "—" means the source doesn't name it
  as a pattern, not that the capability is missing.
- **The match is approximate.** Vendors draw boundaries differently; read the linked section for where
  they differ.
- **The second table is generated** from the `aka` field of every section, so new names added to a
  section appear here automatically.

## Flashcards

Q: What do Anthropic, Google and Microsoft call a fixed sequence of model calls?
A: Prompt chaining (Anthropic, AWS), sequential (Google), sequential orchestration (Microsoft).

Q: What is OpenAI's name for an orchestrator that calls specialist agents as tools?
A: The manager pattern (agents as tools), as opposed to handoffs.

Q: What does Gulli's book call the evaluator-optimizer pattern?
A: Reflection.
