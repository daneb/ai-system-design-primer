# 3.16 Observability: deep dive

Reference material for [3.16 Observability](../3-components/3.16-observability.md). Read that first.

## OpenTelemetry GenAI semantic conventions

| Aspect | Detail | Source |
|---|---|---|
| Status | Every `gen_ai.*` attribute, span and metric is "Development" (formerly experimental); none stable as of mid-2026 | [OTel GenAI](https://opentelemetry.io/docs/specs/semconv/gen-ai/); secondary |
| Home | Moved from the core semantic-conventions repo to a dedicated `semantic-conventions-genai` repo in v1.42.0 (June 2026) | Secondary (several sources agree) |
| Operations (`gen_ai.operation.name`) | `chat`, `embeddings`, `create_agent`, `invoke_agent`, `invoke_workflow`, `execute_tool`, `retrieval`, `plan`, memory operations | Secondary |
| Key attributes | `gen_ai.provider.name` (replaced `gen_ai.system` in v1.37), `gen_ai.request.model`, token usage, `gen_ai.agent.name`/`id`, `gen_ai.tool.name`, `gen_ai.tool.call.id` | Secondary |
| Metrics | client operation duration, token usage, time to first chunk, time per output chunk (v1.41), agent run duration and tool-call counts | Secondary |
| Content | Prompt, completion and tool arguments/results recorded only when opted in | Spec guidance |
| MCP | MCP conventions; MCP 2026-07-28 propagates `traceparent` in `_meta` | [MCP changelog](https://modelcontextprotocol.io/specification/2026-07-28/changelog) |

## What providers ship

| Provider | Tracing | Notes | Source |
|---|---|---|---|
| Microsoft | Foundry tracing to Application Insights; OpenTelemetry-based; integrations for Agent Framework, Semantic Kernel, LangChain/LangGraph and OpenAI Agents SDK | Contributed multi-agent conventions with Cisco Outshift; content recording off by default (`AZURE_TRACING_GEN_AI_CONTENT_RECORDING_ENABLED`); advice to keep secrets out of spans and route sensitive content to a restricted table; GA for prompt and hosted agents, preview for workflows | [Foundry tracing](https://learn.microsoft.com/azure/foundry/observability/concepts/trace-agent-concept) |
| AWS | AgentCore Observability and CloudWatch GenAI observability | Sessions → traces → spans; automatic for AgentCore Runtime; ADOT for agents elsewhere; needs CloudWatch Transaction Search; dashboards by agent and session; AgentCore Evaluations reads the spans | [Get started](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/observability-get-started.html) |
| OpenAI | Agents SDK tracing, on by default, exported to the OpenAI Traces dashboard | Captures generations, tool calls, handoffs and guardrails; `trace_include_sensitive_data` defaults to true; unavailable under Zero Data Retention; custom processors can replace or add exporters | [Tracing](https://openai.github.io/openai-agents-python/tracing/) |
| Google | Cloud Trace for ADK and Vertex AI Agent Engine (OpenTelemetry) | Not verified first-party in this pass | (see PLAN debt) |
| Anthropic | OpenTelemetry metrics and events from Claude Code; API usage and cost reports | No hosted trace viewer for API agents found | (see PLAN debt) |

## Metrics worth alerting on

| Signal | Why | Typical alert |
|---|---|---|
| Error and timeout rate, by tool and model | Outages, rate limits, broken tools | Above baseline for 5–10 minutes |
| p95 latency and time to first token | User experience; queueing ([2.7](2.7-throughput-vs-latency.md)) | Above SLO |
| Tokens and cost per run, per user, per feature | Runaway agents, abuse | Budget threshold; sudden jumps |
| Steps and tool calls per run | Loops | Above cap |
| Cache hit rate | Cost regressions after prompt changes ([3.13](3.13-caching.md)) | Sudden drop |
| Guardrail trigger and refusal rates | Attacks, over-blocking | Shift from baseline |
| Online eval score and user feedback | Silent quality regressions | Drop after a release |

## Risk and controls

| Risk | Reference | Control | Evidence an auditor would ask for |
|---|---|---|---|
| Personal data in traces | GDPR, POPIA; OWASP LLM02 | Metadata by default; content opt-in with redaction; restricted table; retention limits | Telemetry data-flow record; retention config |
| Traces sent to an unapproved third party | Outsourcing and data residency rules | Approve exporters; disable vendor default exporters where needed | Exporter configuration |
| Can't reconstruct a decision | Model risk (e.g. SR 11-7); audit | Trace every step with prompt and model versions; tamper-evident storage for in-scope systems | Sample traces; retention policy |
| Silent quality regression | Model risk | Online evals; feedback; drift alerts | Monitoring reports |
| Runaway cost | OWASP LLM10 | Per-run and per-user cost metrics and alerts | Cost dashboards |
